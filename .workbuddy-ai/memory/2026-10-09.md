## Build gotcha: Google Fonts network fetch

`npm run build` intermittently fails with `Failed to fetch Outfit from Google Fonts`
(`src/app/layout.tsx` uses `next/font/google`). It is **transient/network-dependent, not a
code bug** — a plain retry succeeded. If it happens offline or behind a proxy, either set
`HTTP_PROXY`/`HTTPS_PROXY` or self-host the font with `next/font/local`.
