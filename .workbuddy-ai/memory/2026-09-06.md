### Turbopack root warning (fixed)

User hit: "Next.js ignored package-lock.json in C:\Users\USER because it would
include your home directory ... set `turbopack.root`".

Cause: an 83-byte orphan `package-lock.json` (`{"name":"USER",...,"packages":{}}`)
sits in `C:\Users\USER`, created by running npm from the home directory. Next
walks up the tree looking for a lockfile to infer the project root, found that
one, considered the whole home dir the root, and refused it.

Fix applied: `turbopack: { root: process.cwd() }` in `next.config.ts`. This stops
the upward search, so the stray file no longer matters. Verified - config loaded
with no warning.

different port refuses and reports the existing PID instead of starting.
