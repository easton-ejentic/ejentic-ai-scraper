## Testing setup (reference)

- `npm test` → `vitest run`; `npm run test:watch`. Config in `vitest.config.ts`:
  `environment: node`, `include: ["tests/**/*.test.ts"]`, `timeout: 15s`.
  The `@` alias is mapped to `./src`. **Nothing in the suite touches the network.**
- 171 tests / 10 files: discovery 50, safety 38, extraction 16, campaigns 12,
  auth 11, url 11, evaluation 9, site-config 9, postgresql-pipeline 9, queue-limit 6.
- `tests/postgresql-pipeline.test.ts` drives the Postgres repository against an
  **in-memory Prisma stand-in** (`vi.mock` of `src/lib/production/db`), not a real
  database. Only CI's migrate job touches real Postgres.

Gaps: no E2E, no load tests, no worker/queue tests.

Manual smoke: `npm run dev` + `npm run worker` in a second terminal. Use a public
URL you control — never localhost, private IPs or cloud metadata endpoints (the
safety suite enforces this). `/api/health` reports active provider and backend;
`/settings` shows which datastore/queue is live.
